# 📊 Student Spend Analysis | Power BI

## 📌 Project Overview

This Power BI project analyzes student purchasing behavior across different product categories, age groups, store locations, and store settings. The goal of the project is to transform student survey data into an interactive dashboard that makes spending patterns and purchasing preferences easy to understand.

The report uses interactive visualizations, filters, and multiple analytical views to explore how student spending varies across demographics, products, and store characteristics.

---

## 🎯 Project Objectives

The analysis was designed to answer questions such as:

- How does student spending vary across different store locations and settings?
- Which product categories receive the highest spending?
- How do purchasing patterns differ among student age groups?
- How does spending on outdoor sports products vary by age?
- How does video game spending compare across age groups?
- How does academic book spending differ by store location?
- How does gadget spending change over time?
- How are stores distributed across different locations and settings?

---

## 📊 Dashboard Analysis

The Power BI report contains multiple interactive report pages covering different aspects of student purchasing behavior.

### 🛍️ Purchase & Store Analysis

The dashboard examines student purchases based on:

- Store Location
- Store Setting
- Product Category
- Student Age
- Purchase Amount

Interactive filters allow users to explore spending patterns for specific store locations and store settings.

### 🎓 Student Spending Analysis

Student spending is analyzed across several categories, including:

- Academic Books
- Outdoor Sports
- Indoor Sports
- Video Games
- Gadgets

The report compares purchasing behavior across different student age groups to identify differences in spending preferences.

### 📍 Location Analysis

The dashboard evaluates purchasing activity across store locations and settings, helping identify geographic differences in student spending behavior.

Key analysis includes:

- Total purchases by location
- Academic book spending by store location
- Outdoor sports purchases by location
- Number of stores by location and store setting

### 📈 Spending Trends

The report also explores changes in student spending over time, including gadget purchases, allowing trends and changes in purchasing behavior to be identified visually.

---

## 🔍 Key Insights

The dashboard enables users to identify:

- Differences in student purchasing behavior across age groups
- Product categories that attract higher student spending
- Variations in purchases across store locations
- Differences between various store settings
- Spending patterns for academic books, sports products, video games, and gadgets
- Changes in purchasing behavior over time

These insights can help retailers better understand student customers and support decisions related to product assortment, store strategy, and targeted marketing.

## 🚀 How to Use

1. Download the `Student-Spend-Analysis.pbix` file.

4. Use the available slicers and filters to explore the data interactively.
